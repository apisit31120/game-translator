# 🎮 Game Translator - Visual Overlay Edition

**แปลภาษาเกม PC แบบลากกรอบเองได้ พร้อมปรับสีและตำแหน่งได้**

โปรแกรม Python สำหรับแคปหน้าจอเกม → OCR ดึงข้อความ → แปลเป็นไทย → แสดงผลแบบ Overlay

---

## ✨ Features

- 🖱️ **ลากกรอบแปลเองได้** - เลือกพื้นที่ที่ต้องการ OCR
- 📍 **ลากตำแหน่งแสดงผลเองได้** - วางไว้ตรงไหนก็ได้บนหน้าจอ
- 🎨 **ปรับสีได้** - พื้นหลัง, ตัวอักษร, กรอบ
- 👁️ **ปรับความโปร่งใสได้** - ไม่บังเกม
- 💾 **บันทึกการตั้งค่าอัตโนมัติ** - เปิดมาใช้ได้ทันที
- 🌐 **แปลภาษาไทยสมบูรณ์** - แสดงผลถูกต้อง ไม่มี `?????`

## 🎮 วิธีใช้งาน

### รันโปรแกรม
```bash
python game_translator.py
```

### ขั้นตอนการใช้งาน

#### 1️⃣ ตั้งค่าครั้งแรก (กด `F8`)
```
🔧 โหมดตั้งค่า (แบบง่าย)

   1 = ตั้งค่ากรอบแปล (กรอกตำแหน่ง)
   2 = ตั้งค่าตำแหน่งแสดงผล
   3 = ปรับสีพื้นหลัง
   4 = ปรับสีตัวอักษร
   5 = ปรับความโปร่งใส
   6 = ดูการตั้งค่าปัจจุบัน
   0 = เสร็จสิ้น
```

**วิธีหาตำแหน่ง:**
1. เปิดเกมไว้
2. กด `F8` เลือก `1` (ตั้งค่ากรอบแปล)
3. กรอกตำแหน่ง X, Y, ความกว้าง, ความสูง
   - X = ระยะจากขอบซ้ายจอ
   - Y = ระยะจากขอบบนจอ
   - ดูตำแหน่งได้โดยใช้ `Snipping Tool` หรือ `ShareX`

#### 2️⃣ ใช้งานปกติ
- กด `F9` = แปลทันที
- กด `F10` = เปิด/ปิดการแสดงผล
- กด `ESC` = ออกจากโปรแกรม

## ⌨️ Hotkeys สรุป

| ปุ่ม | ฟังก์ชัน |
|-----|----------|
| `F8` | เข้าโหมดตั้งค่า (CLI) |
| `F9` | แปลทันที |
| `F10` | เปิด/ปิดแสดงผล |
| `ESC` | ออกจากโปรแกรม |

### โหมดตั้งค่า (F8)
| ตัวเลข | ฟังก์ชัน |
|--------|----------|
| `1` | ตั้งค่ากรอบแปล (กรอกตำแหน่ง) |
| `2` | ตั้งค่าตำแหน่งแสดงผล |
| `3` | เปลี่ยนสีพื้นหลัง |
| `4` | เปลี่ยนสีตัวอักษร |
| `5` | เปลี่ยนความโปร่งใส |
| `6` | ดูการตั้งค่าปัจจุบัน |
| `0` | เสร็จสิ้น |

## 🎨 การตั้งค่าสี

### สีพื้นหลัง (กด `B`)
- เทาเข้ม (default)
- ดำ
- แดงเข้ม
- เขียวเข้ม
- น้ำเงินเข้ม
- น้ำตาล
- ม่วงเข้ม

### สีตัวอักษร (กด `T`)
- ขาวเหลือง (default)

- เขียวอ่อน
- ฟ้าอ่อน
- ชมพูอ่อน
- เหลือง
- ฟ้า cyan

### ความโปร่งใส (กด `O`)
- 0.9 (default) - แทบไม่โปร่ง
- 0.7 - โปร่งปานกลาง
- 0.5 - โปร่งมาก

## 🔧 แก้ไขปัญหา

### "TesseractNotFoundError"
ติดตั้ง Tesseract ไม่สำเร็จ หรือติดตั้งที่ path อื่น

แก้ไข: เปิด `game_translator.py` แก้ path:
```python
pytesseract.pytesseract.tesseract_cmd = r'C:\Your\Path\To\tesseract.exe'
```

### ภาษาไทยแสดงเป็น `?????`
ติดตั้ง font ไทยใน Windows:
- TH Sarabun New (โหลดจาก f0nt.com)
- หรือ Windows จะใช้ Tahoma แทนอัตโนมัติ

### ไม่สามารถลากกรอบได้
- ต้องกด `S` หรือ `D` ก่อนลาก
- ต้องลากจากซ้ายบนไปขวาล่าง

### หน้าต่างแสดงผลหายไป
กด `F10` เพื่อเปิด/ปิดการแสดงผล
