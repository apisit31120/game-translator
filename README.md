# 🎮 Game Translator - Borderless Overlay Edition

**แปลภาษาเกม PC แบบลากเมาส์ได้ พร้อมหน้าต่างลอยไร้ขอบ (Borderless)**

โปรแกรม Python สำหรับแคปหน้าจอเกม → OCR ดึงข้อความ → แปลเป็นไทย → แสดงผลแบบ Overlay ลอยบนหน้าจอไร้ขอบ

---

## ✨ Features

- 🖱️ **ลากเมาส์เลือกพื้นที่** - มีกรอบแสดงผลขณะลาก พร้อมแสดงขนาด (WxH)
- 🎨 **หน้าต่างลอยไร้ขอบ** - ไม่มี title bar เหมือนเป็นส่วนหนึ่งของเกม
- 📜 **รองรับข้อความยาว** - OCR แบบปรับปรุง + แปลหลายช่วง + แสดงผล scroll ได้
- 🌫️ **ปรับความโปร่งใสได้** - ไม่บังเกม
- 🖐️ **ลากย้ายได้** - คลิกซ้างค้างแล้วลากย้ายตำแหน่งได้
- 💾 **บันทึกการตั้งค้าอัตโนมัติ**

## 🎮 วิธีใช้งาน

### รันโปรแกรม
```bash
python game_translator.py
```

### ตั้งค่าครั้งแรก (กด `F8`)

#### 1. ตั้งค่ากรอบแปล (กด `1`)
- หน้าจอเต็มจอ พร้อมให้ลากเมาส์
- **คลิกซ้ายค้าง** แล้ว **ลาก** เลือกพื้นที่ที่มีข้อความในเกม
- จะมี **กรอบสีฟ้าโปร่งใส** ตามเมาส์ พร้อมแสดงขนาด (เช่น `300x150`)
- **ปล่อยเมาส์** เพื่อยืนยัน

#### 2. ตั้งค่าตำแหน่งแสดงผล (กด `2`)
- ทำเหมือนกัน แต่เลือกตำแหน่งที่จะให้กรอบแปลลอยอยู่

#### 3. ปรับสีและความโปร่งใส (กด `3`, `4`, `5`)

### ใช้งานปกติ

| ปุ่ม | ฟังก์ชัน |
|-----|----------|
| `F8` | เปิดโหมดตั้งค่า |
| `F9` | แปลทันที |
| `F10` | เปิด/ปิดการแสดงผล |
| `ESC` | ออกจากโปรแกรม |

### จัดการหน้าต่างแสดงผล

| การทำงาน | วิธี |
|---------|------|
| **ลากย้าย** | คลิกซ้ายค้างบนกรอบ แล้วลาก |
| **ปิด** | คลิกขวาที่กรอบ |

## 🎨 ลักษณะหน้าต่างแสดงผล (Borderless)

```
┌─────────────────────────────────┐
│                                 │
│ ▌ ข้อความภาษาไทยที่แปลแล้ว      │
│ ▌ รองรับหลายบรรทัด              │
│ ▌ และข้อความยาวๆ ด้วย          │
│ ▌ (ลากย้ายได้)                  │
│                                 │
│   F9=แปล | F10=ซ่อน/แสดง       │
└─────────────────────────────────┘
▲ เส้น accent สีฟ้าด้านซ้าย (ไม่มี title bar)
```

- **ไม่มี Title Bar** - ดูเหมือนเป็นส่วนหนึ่งของเกม
- **พื้นหลัง:** ดำโปร่งใส
- **เส้น accent:** สีฟ้าด้านซ้าย
- **รองรับ scroll:** สำหรับข้อความยาว
- **ลากย้ายได้:** คลิกซ้ายค้างแล้วลาก

## 🔧 แก้ไขปัญหา

### "TesseractNotFoundError"
แก้ไข path ใน `game_translator.py` บรรทัดที่ 10:
```python
pytesseract.pytesseract.tesseract_cmd = r'C:\Your\Path\To\tesseract.exe'
```

### ภาษาไทยแสดงเป็น `?????`
ติดตั้ง font ไทยใน Windows (TH Sarabun New หรือ Tahoma)

### หน้าต่างแสดงผลไม่ขึ้น
- ตรวจสอบว่าตั้งค่าตำแหน่งแสดงผลแล้ว (กด F8 → 2)
- ตรวจสอบว่าไม่ได้กด F10 ซ่อนไว้
