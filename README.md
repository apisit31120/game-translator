# 🎮 Game Translator - Modern Overlay Edition

**แปลภาษาเกม PC แบบลากเมาส์ได้ พร้อมหน้าต่างลอยสวยงาม**

โปรแกรม Python สำหรับแคปหน้าจอเกม → OCR ดึงข้อความ → แปลเป็นไทย → แสดงผลแบบ Overlay ลอยบนหน้าจอ

---

## ✨ Features

- 🖱️ **ลากเมาส์เลือกพื้นที่** - มีกรอบแสดงผลขณะลาก พร้อมแสดงขนาด (WxH)
- 🎨 **หน้าต่างลอย Modern** - ดีไซน์สวยงาม มีเส้นขอบ accent สีฟ้า
- 🌫️ **ปรับความโปร่งใสได้** - ไม่บังเกม
- 💾 **บันทึกการตั้งค้าอัตโนมัติ** - เปิดมาใช้ได้ทันที
- 🇹🇭 **แสดงเฉพาะภาษาไทย** - ไม่มีข้อความ EN กวนใจ

## 🎮 วิธีใช้งาน

### รันโปรแกรม
```bash
python game_translator.py
```

### ตั้งค่าครั้งแรก (กด `F8`)

#### 1. ตั้งค่ากรอบแปล (กด `1`)
- หน้าจอจะเต็มจอ พร้อมให้ลากเมาส์
- **คลิกซ้ายค้าง** แล้ว **ลาก** เลือกพื้นที่ที่มีข้อความในเกม
- จะมี **กรอบสีฟ้า** ตามเมาส์ พร้อมแสดงขนาด (เช่น `300x150`)
- **ปล่อยเมาส์** เพื่อยืนยัน
- กด `ESC` เพื่อยกเลิก

#### 2. ตั้งค่าตำแหน่งแสดงผล (กด `2`)
- ทำเหมือนกัน แต่เลือกตำแหน่งที่จะให้กรอบแปลลอยอยู่
- ขนาดกรอบจะปรับอัตโนมัติตามข้อความ

#### 3. ปรับสีและความโปร่งใส (กด `3`, `4`, `5`)

### ใช้งานปกติ

| ปุ่ม | ฟังก์ชัน |
|-----|----------|
| `F8` | เปิดโหมดตั้งค่า |
| `F9` | แปลทันที |
| `F10` | เปิด/ปิดการแสดงผล |
| `ESC` | ออกจากโปรแกรม |

## 🎨 ลักษณะหน้าต่างแสดงผล

```
┌─[สีฟ้า accent]─────────────────┐
│                                │
│   ข้อความภาษาไทยที่แปลแล้ว     │
│   จะแสดงอยู่ในกรอบนี้          │
│                                │
│   F9=แปล | F10=ซ่อน/แสดง      │
└────────────────────────────────┘
```

- **พื้นหลัง:** ดำโปร่งใส
- **ขอบ:** มน พร้อมเส้น accent สีฟ้าด้านซ้าย
- **ตัวอักษร:** สีขาว อ่านง่าย
- **ปรับขนาดอัตโนมัติ:** ตามความยาวข้อความ
